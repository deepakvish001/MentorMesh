# Changelog

All notable changes to MentorMesh are documented here.

## 1.0.0 - 2026-09-06

### Added

- Validated mentor and learner profile registry
- Explainable, ranked mentor matching
- Conflict-safe mentoring session lifecycle
- Learning goals and milestone tracking
- REST API with safe domain error responses
- Atomic restart-safe JSON persistence
- Fail-closed API-key authentication and coordinator authorization
- Non-root production container and Docker build verification in CI
