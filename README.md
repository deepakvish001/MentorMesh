# MentorMesh

A mentorship operations platform for communities, colleges, and internal learning programs.

MentorMesh helps coordinators match mentors with learners, publish availability, book sessions, define goals, and collect structured feedback without managing the program in spreadsheets.

## Core capabilities

- Mentor expertise and availability profiles
- Learner goals and preferences
- Explainable mentor matching
- Session booking and lifecycle tracking
- Goal milestones and feedback
- Coordinator reporting and audit history

## Technology

Node.js 22, NestJS, TypeScript, PostgreSQL, Jest-compatible Node tests, and GitHub Actions.

## Local setup

1. Install Node.js 22 and PostgreSQL.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Start development with `npm run start:dev`.

## Quality commands
